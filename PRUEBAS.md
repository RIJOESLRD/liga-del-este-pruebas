# Copia de pruebas de la web de la Liga del Este

Esta es una COPIA para probar cambios: https://rijoeslrd.github.io/liga-del-este-pruebas/
La web oficial está en el repositorio RIJOESLRD/liga-del-este-web y no se toca desde aquí.

Diferencias con la oficial (no se pasan a la oficial):
- Franja amarilla "VERSIÓN DE PRUEBA" en todas las páginas y Google no la indexa (MODO_PRUEBA en el workflow).
- El panel /admin guarda las noticias en este repositorio de pruebas.
- El boletín (Brevo) está desactivado para no mezclar suscripciones con la lista real.

Cuando un cambio esté aprobado, se copia a la web oficial.
