Entrar al panel

Para publicar necesitas tu clave de acceso de GitHub. Se crea una sola vez y queda guardada en este teléfono o computadora.

¿Cómo creo mi clave? (una sola vez)
  1. Abre github.com/settings/personal-access-tokens/new con tu cuenta de GitHub.
  2. Token name: Panel de noticias.
  3. Expiration: elige Custom y pon una fecha dentro de un año.
  4. Repository access: elige Only select repositories y marca liga-del-este-web.
  5. Permissions → Repository permissions → Contents: elige Read and write.
  6. Toca Generate token, copia la clave (empieza con github_pat_) y pégala arriba.

La clave solo sirve para la web de la liga. No la compartas. Si la pierdes o cambias de teléfono, crea otra igual.
